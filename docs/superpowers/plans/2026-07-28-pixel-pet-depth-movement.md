# 2D 像素宠物四向移动实施计划

## 成功条件

- 四向移动、尺寸滑块、自适应阴影、食盆与球锚点、慢速一次性动作全部
  有可复核代码和测试证据；
- 产品文档与 `REQUIREMENTS_AND_BUGS.md` 反映最终行为；
- Web 测试、类型检查、构建和三个目标视口的真实浏览器检查全部通过；
- 不提交、不推送。

## 步骤

1. **扩展领域模型**
   - 增加前后移动状态、二维位置边界、方向和景深计算函数。
   - 将一次性动作帧时长增加约 `45%`。
   - 验证：模型单测覆盖四向 reducer、二维 clamp、景深和时长。

2. **增加宠物互动锚点**
   - 为五只宠物定义食盆、球和阴影宽度。
   - 验证：目录单测检查全部锚点存在且位于单元格内。

3. **重构舞台定位**
   - 将宠物、阴影和道具放入共享舞台锚点。
   - 增加二维位置、前后移动循环、四方向键与四向按钮。
   - 增加 `70%–125%` 尺寸滑块和当前值。
   - 验证：组件单测覆盖按钮、键盘、边界、滑块和样式变量。

4. **修复互动对位**
   - 食盆使用嘴部锚点。
   - 玩球使用头部前方锚点，边缘时同步切换安全方向。
   - 阴影随尺寸、景深和跳跃状态变化。
   - 验证：组件测试检查共享锚点、方向与每只宠物的锚点值。

5. **更新产品文档和协作登记**
   - 更新功能规格中的状态、移动、道具、响应式和验收章节。
   - 登记一个已接受需求和两个已确认 Bug，完成后补验证证据。

6. **自动验证**
   - 运行相关测试，再运行完整 Web 测试、类型检查和生产构建。
   - 运行 `git diff --check`。

7. **真实浏览器验收**
   - 启动本地服务。
   - 在桌面、`578×863`、`390×844` 检查四向边界、两端尺寸、阴影、
     五宠物食盆、左右边界玩球、键盘与焦点、页面溢出和控制台。
   - 将测量结果写入新的 QA JSON。
