# 2D 像素宠物四向移动与互动对位设计

## 1. 状态

- 日期：2026-07-28
- 方案：用户确认 A，采用 2.5D 四向移动
- 范围：现有五只宠物、六个场景和互动舞台
- 不包含：重新生成正面或背面行走图集、3D、体素、WebGL

## 2. 目标

用户可以让宠物在舞台中左右移动，也可以让它向前靠近镜头或向后深入
场景；用户可以用滑块调整宠物大小。宠物的位置和尺寸变化时，阴影、
食盆与玩具球必须同步变化，并与动作中的嘴部或头部保持视觉对位。
一次性互动动作需要比现有版本更慢，以便用户看清完整过程。

## 3. 视觉与交互原则

- **视觉主张：** 宠物始终是舞台唯一焦点，景深和阴影只强化空间感，
  不增加新的装饰层。
- **内容结构：** 保留现有宠物与场景选择、主要舞台和互动操作区；
  方向控制改为四向，旁边增加一个紧凑的尺寸滑块。
- **互动主张：**
  1. 向上移动代表远离镜头，宠物和阴影略小；
  2. 向下移动代表靠近镜头，宠物和阴影略大；
  3. 食盆与球使用宠物局部锚点，不再使用场景级固定偏移。

## 4. 四向移动

舞台位置由单一数值改为二维坐标：

```ts
interface StagePosition {
  x: number;
  y: number;
}
```

- `x` 控制左右位置；
- `y` 控制前后景深；
- 初始位置为 `{ x: 50, y: 50 }`；
- 左右按钮和 `ArrowLeft` / `ArrowRight` 控制 `x`；
- 向后按钮和 `ArrowUp` 减小 `y`，宠物深入场景；
- 向前按钮和 `ArrowDown` 增大 `y`，宠物靠近镜头；
- 松开按键、指针离开或释放按钮后停止移动；
- 四个方向均有舞台边界，不得继续累积越界位置。

现有图集没有正面和背面行走行。左右移动继续使用原有左右步态；
前后移动复用正面空闲帧，并通过轻微的像素级上下起伏表现步态。
这属于用户确认的 2.5D 方案，不伪装成新增了正背面素材。

## 5. 尺寸与景深

尺寸滑块范围为 `70%–125%`，默认 `100%`，步长 `5%`。最终显示大小由：

```text
响应式基础尺寸 × 用户尺寸 × 景深比例
```

共同决定。景深比例从后景到前景约为 `0.90–1.08`。用户尺寸不因切换
宠物或场景而重置。滑块具有可见标签、当前百分比和原生键盘操作。

位置边界需要考虑当前显示尺寸，避免大尺寸宠物在目标视口中完全离开
场景。桌面和移动端可以使用不同的响应式基础尺寸，但用户看到的滑块
百分比语义保持一致。

## 6. 阴影

阴影与宠物共用同一个舞台锚点：

- 宠物变大时，阴影同步变宽、略微变高；
- 宠物进入前景时，阴影略深；进入后景时略浅；
- 跳跃时阴影收缩并降低透明度；
- 减少动画模式下仍保留正确静态尺寸，不播放过渡动画。

阴影不得再依赖一个与宠物缩放无关的固定伪元素尺寸。

## 7. 食盆与玩具球锚点

每只宠物在目录中增加局部互动锚点。锚点以 `192×208` 单元格坐标为
基准，并随宠物整体缩放：

```ts
interface PetInteractionAnchors {
  bowl: { x: number; y: number };
  ball: { x: number; y: number };
  shadowWidth: number;
}
```

- 食盆锚定在进食动作中嘴部的下前方，不再只根据舞台左右位置放在
  宠物身体外侧；
- 玩具球锚定在玩球动作中头部朝向的前方；
- 当宠物靠近左右边界时，玩球动作与球一起切换到安全方向，使球既在
  头部前方又完整留在舞台内；
- 其他互动道具保留现有语义，但跟随新的二维舞台位置和整体尺寸。

## 8. 动画速度

只放慢一次性互动，不降低移动控制响应，也不改变等待和睡眠阈值。

- 开心、跳跃、喂食、玩球、梳毛、洗澡、跳舞和拍照的帧时长统一增加
  约 `45%`；
- 循环呼吸、左右移动、等待、睡眠和抚摸保持原节奏；
- `prefers-reduced-motion: reduce` 下继续跳过循环动画，一次性动作快速
  完成，不强迫用户观看慢动画。

## 9. 无障碍

- 四个方向按钮均有准确的中文可访问名称；
- 房间聚焦后支持四个方向键；
- 尺寸滑块使用原生 `input[type="range"]`，具有关联标签和当前百分比；
- 状态反馈继续使用唯一的 `role="status"`；
- 视觉上的上下方向与读屏名称明确区分“向前”和“向后”。

## 10. 验收标准

1. 指针和键盘均可连续控制四个方向，松开后停止，位置不越界。
2. 向前时宠物靠近并略大，向后时深入并略小。
3. 尺寸滑块可在 `70%–125%` 间选择，宠物、阴影和道具同步变化。
4. 五只宠物的食盆均位于进食动作嘴部下前方。
5. 玩具球位于头部前方，左右边界不出场景。
6. 一次性互动总时长比旧版约增加 `45%`，移动和待机节奏不受影响。
7. 自动测试、类型检查和生产构建通过。
8. 在桌面、`578×863`、`390×844` 真实浏览器中验证移动边界、最大和
   最小尺寸、食盆、玩球、焦点与横向溢出。
9. 浏览器控制台无新增 warning 或 error。
